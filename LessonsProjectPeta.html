Topics for Cloud Computing

Cloud Computing is the on demand delivery of computing services, including servers, storage, databases, networking, software and analytics over the internet. Maintaining physical data centers or local hard drives are hard to do so and takes spaces thats why users can access cloud providers like Amazon Web Services, Microsoft Azure or Google Cloud but you have to pay as you go.


1. Infrastructure as a Service (IaaS)

Definition
Infrastructure as a Service delivers fundamental computing resources over the internet on a pay-as-you-go basis. It provides access to raw, virtualized hardware components, enabling full control over the underlying architecture.

Key Components
Virtualized physical servers and Compute instances
Storage resources (Block, File, and Object storage)
Network infrastructure (Routers, Switches, Subnets, and Firewalls)

Responsibility Model
Provider Managed: Physical hardware, data center facilities, virtualization layer, physical networking.
User Managed: Operating systems, runtime environments, middleware, database management, network configuration, application security, and application deployment.

Primary Use Cases & Examples
Use Cases: Enterprise data center migrations, disaster recovery, cloud bursting, high-performance computing (HPC).
Examples: Amazon Web Services (AWS EC2), Google Compute Engine (GCE), Microsoft Azure Virtual Machines.

2. Platform as a Service (PaaS)

Definition
Platform as a Service provides a hardware and software framework designed for application development, testing, and deployment. PaaS abstracts the underlying infrastructure, allowing developers to focus strictly on software delivery without managing server hardware or OS administration.

Key Components
Execution runtimes and programming language frameworks
Managed database management systems (DBMS)
Integrated deployment pipelines and web server environments

Responsibility Model
Provider Managed: Physical infrastructure, OS maintenance, security patching, virtualization, runtime environment maintenance, middleware updates.
User Managed: Application source code, application configuration, user access management, and business logic data.

Primary Use Cases & Examples
Use Cases: Rapid application development (RAD), API development and management, microservices deployment, web application hosting.
Examples: Google App Engine, Heroku, AWS Elastic Beanstalk, Microsoft Azure App Service.

3. Software as a Service (SaaS)

Definition
Software as a Service delivers complete, fully functional applications hosted on cloud infrastructure and accessible via web browsers, thin clients, or API endpoints. It removes the need for local software installation and maintenance.

Key Components
Fully managed cloud application software
Automated background updates, security patches, and backups
Multi-tenant architectural provisioning

Responsibility Model
Provider Managed: Entire infrastructure stack, operating systems, applications, data security mechanisms, feature updates, uptime SLAs.
User Managed: End-user account credentials, data access policies, organization-level configurations.

Primary Use Cases & Examples
Primary Use Cases & Examples Use Cases: Enterprise resource planning (ERP), customer relationship management (CRM), collaborative productivity suites, cloud file management.
Examples: Google Workspace, Salesforce, Microsoft 365, Canva.
